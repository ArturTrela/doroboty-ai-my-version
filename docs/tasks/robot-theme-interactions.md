# Robot theme interaction and candidate account

## Intent

Use engraved metal plates and gold focus/hover feedback on the requested public actions and persona selection. Keep PCB offer titles legible on hover. Give the listing slogan the same Ethnocentric Italic treatment as the landing slogan. Apply the same palette and components to the candidate overview and profile.

Candidate selection goes to the editable profile by default. Contextual continuation links keep their existing destinations and the overview remains accessible from navigation and the account link.

## Assets

The listing slogan is fixed artwork rasterized from Ethnocentric Italic supplied by Typodermic Fonts in its free desktop collection. See https://typodermicfonts.com/desktop/. The full Polish text is the accessible heading name.
