Zakładka zachowuje stałą nazwę i zmienia aria-pressed. To opisana decyzja pakietu. Focus obejrzysz, przechodząc klawiszem Tab.

Struktura HTML
<button class="button button-primary" type="button">
  Otwórz informacje <!-- decorative icon -->
</button>
<a class="button" href="#cards">Przykładowe oferty</a>
<button class="save-button" type="button"
  aria-pressed="false" aria-label="Zapisz ofertę przykładową">
  <!-- decorative bookmark SVG -->
</button>

Label, wartość i kontekst.

Pole liczbowe ma zakres 0–100000, krok 1 i osobną jednostkę. Wpisz 100001, a następnie wybierz „Sprawdź wartość”, aby sprawdzić natywny komunikat przeglądarki. Nie dodajemy nowego koloru błędu do zatwierdzonej palety.

Kategorie i aktywne kryteria

Selektor pokazuje stan pojedynczego wyboru. Filtrowanie całego zbioru jest dostępne w przykładzie listingu. To przyciski, bez ról tab/tabpanel.

Wszystkie oferty

Jedna anatomia, różna treść

Oferta podstawowa, długi tytuł z inicjałami firmy oraz brak wynagrodzenia. Każda karta używa jobCard(job, saved, href); przyciski zapisu działają, a linki prowadzą do pełnych ofert.

Użycie modułu JavaScript
import { jobCard, offerURL } from '../components/ui.js';

const saved = new Set();
const href = offerURL(job.id, '', saved);
container.innerHTML = jobCard(job, saved, href);
// Handle [data-save] in your controller, then update state and re-render.

Fakty i tożsamość

Różowa płaca jest informacją. Inicjały są fallbackiem znaku firmy. Te elementy nie otrzymują roli przycisku ani tabIndex.

Dialog z istniejącego systemu.
