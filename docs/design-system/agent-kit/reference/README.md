# DoRoboty.ai — dokumentacja dla designerów · v1

Otwórz `index.html` w przeglądarce. Cała dokumentacja działa lokalnie; nie wymaga uruchamiania aplikacji ani instalacji pakietów.

- `index.html`: pełny dokument z nawigacją, fragmentami zrzutów i galerią.
- `components.md`: ten sam pełny tekst w Markdown.
- `evidence/`: 19 zachowanych zrzutów, metadane viewportów i sumy kontrolne uzupełniających źródeł.

Status: do oceny, 2 listopada 2026. Zakres: 22 rodziny komponentów listingu i pełnej oferty pracy. Oznaczenia odróżniają obserwację od rekomendacji i testu do wykonania. Nie jest to pakiet implementacyjny dla agenta.
