# Frontend teaching prototypes need an explicit tooling boundary

Removing backend code alone leaves agents following obsolete setup instructions. Update root agent guidance, scripts, package dependencies, CI, current product docs and the behavior register together. Keep original program materials outside participant packages.

Use local JSON and shared plain-function transitions instead of reproducing a server API in the browser. Exercise the complete candidate/employer story, persistence failure and import recovery. Group map markers by location when a local illustration replaces an external map.

Distribution fingerprints belong to pristine release validation; ordinary participant checks must still allow code edits, installed packages and build artifacts.
